# Giuseppe D'Ambruoso

PhD student in quantum machine learning in the Quantum Theory group of the Polytechnic University of Bari and, until March 2027, Cooperation Associate at CERN, in the Quantum Technology Initiative.

My main topic is quantum machine learning: I study how a symmetry of the data, once built into a quantum neural network, changes what the model learns. I also work on:

- quantum algorithms for anomaly detection in time series;
- analog quantum simulation on Rydberg-atom arrays;
- quantum annealing for optimization problems in Earth observation;
- classification of sub-diffraction images with trained optical measurements;
- quantum key distribution.

I release the code of my papers so that every result can be reproduced.
